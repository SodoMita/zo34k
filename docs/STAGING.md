# Staging cheat sheet — short tags (pumpkin farm edition)

## Examples
```text
#show=mira
#show=mira:smile
#show=mira@left
#show=mira:smile@left
#move=mira@center
#move=mira@center?t=0.8
#move=mira?by=100 0
#move=mira?by=0.5 0 0
#move=mira@640 700
#hide=mira
#hide=mira@off_left
#focus=mira
#anim=mira:wave
#video=intro
#video=intro:stop
#stage=classroom
#stage=2d
#show=scarecrow@right
#show=tykvochka@left
#move=scarecrow@center?t=0.5
```

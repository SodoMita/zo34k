# 🎃 Тыквенная Ферма — zo34k

Уютный визуальный роман-симулятор о выращивании тыквы, построенный на **Godot 4.7.2** + **Dialogue Manager** (шаблон [vn_dialogue_demo](https://github.com/SodoMita/vn_dialogue_demo)).

> Демо-контент школы/крыши полностью удалён. Весь мир заменён на осеннюю ферму.

## Сюжет

Вам достался заброшенный клочок земли — *«Тыквенный Уголок»*. До Хэллоуинского фестиваля 30 дней. Сможете ли вы вырастить **тыкву-чемпиона** (30+ кг) и стать Королём Тыкв?

Вас ждут:
- 🧑‍🌾 Бабушка **Мира** — мудрая наставница с 30-летним стажем
- 🎃 **Пугало Тыквин** — болтливый страж поля с тыквой-головой
- ✨ **Тыквочка** — дух тыквы, которая растёт вместе с вами
- 🌧️ Погода, сорняки, вороны, рынок и ночные события

## Главное меню

Стартовая сцена `scenes/title_screen.tscn` оформлена в тёплой осенней палитре:
- Контрастное меню с подписями действий, понятным фокусом и крупными зонами нажатия
- Осенний градиентный фон и лёгкая анимация листьев (`assets/ui/pumpkin_backdrop.svg`, `pumpkin_leaf.svg`)
- Маскот Тыквочка в отдельной рамке (`scenes/character/tykvo_mascot.tscn`) — idle-дыхание и приветственный прыжок
- **Играть**, **Продолжить** (последнее `user://saves/slot_*.json`), **Настройки** и **Выйти**
- Адаптивная компоновка для широкого и портретного экранов; общие настройки сохраняются в `user://settings.json`
- Скриншот после проверки в Xvfb: `docs/title_pumpkin.webp`

## Геймплей

Каждый день — выбор действий:

| Действие | Эффект |
|----------|--------|
| **Посадить** | Тратит 1 семечко, создаёт грядку |
| **Полить** | +35 влаги, +5 здоровья, +8 роста (перелив опасен!) |
| **Удобрить** | +15 здоровья, +18 роста, убирает вредителей (шанс) |
| **Прополоть** | Убирает сорняки, +10 здоровья |
| **Поговорить** | +8 здоровья, дружба с Тыквочкой |
| **Рынок** | Купить семена (8💰), удобрение (10💰), воду (5💰/2шт) |
| **Собрать урожай** | С 6-й стадии, цена зависит от веса × качества |

**Стадии роста:** пустая → семечко → росток → плеть → цветок → завязь → зелёная тыква → спелая 🎃 → ГИГАНТ!

**Качество:** обычная → хорошая → отличная → легендарная (зависит от здоровья и идеальных дней)

**4 концовки:**
- 🏆 **Король Тыкв** — 30+ кг и репутация 20+
- 🌾 **Рыночный фаворит** — 12+ кг
- 🍂 **Уютный урожай** — 2+ тыквы
- 🌧️ **Урок осени** — иначе (попробуйте снова!)

## Управление

Как в оригинальном шаблоне:
- **Enter / Клик** — далее (дожимает печатную машинку, затем продолжает)
- **Ctrl (удержать)** — скип (ускорение)
- **H** — история с откатом
- **F5 / F9** — быстрое сохранение/загрузка (слот 0, `user://saves/slot_*.json` + миниатюра)
- **Esc / ПКМ** — пауза
- **F12** — паника/босс-экран

Снизу — системная строка: `QS QL Save Load Auto Skip < Выбор > Log Set Panic`

На телефоне: тап = далее, свайп вверх = история, все кнопки — тач-цели, портретная раскладка.

## Тема интерфейса

Полностью перекрашен в **осеннюю палитру**:
- Тёмно-коричневый фон `#1a0d03` / `#2a1607`
- Тыквенно-оранжевый акцент `#ff8c2f` / `#d76b00`
- Тёплые панели вместо холодных синих
- Новый иконка — милая тыква
- Фоны: поле, закат, амбар, рынок, дождь, фестиваль
- Персонажи: Мира, Тыквин, Тыквочка (по 2 эмоции each)

## Технологии (унаследовано от шаблона)

- `Dialogue Manager` v4.1.0, кастомный баллон `vn_balloon.tscn`
- Теги: `#bg=`, `#sprite=`, `#focus=`, `#music=`, `#sfx=`, `#box=`, `#show=`, `#move=`, `#hide=`, `#anim=`, `#stage=`, `#video=`
- История с откатом, сохранения с миниатюрами, авто/скип (в т.ч. «только прочитанное»), настройки (скорость текста, размер, громкости, масштаб UI)
- Процедурная музыка (4 темы) + OGG-петли `assets/music/day.ogg`/`night.ogg`
- Голоса/эффекты через `AudioDirector`
